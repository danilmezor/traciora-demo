# work.calendar_event_participant

One row per invited person on a meeting (the organiser is not repeated). response invited, accepted, declined or tentative. attended true or false once someone recorded it, empty before the meeting or when nobody did. "How often was X there": occurrences held, X's rows, attended true over occurrences held; say how many had no record.
