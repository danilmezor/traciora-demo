# traciora.message_facts

One row per message that counts: kind customer, manager (a staff member's public reply; user_id is their Chatwoot user id), assistant (the bot's public reply) or note (any private message). Activity lines and templates are left out. created_at is UTC. Count a person's replies by user_id and kind manager.
